# Wedding Planner Pro — Web App

A complete, all-in-one wedding planning web app by [TheBridalDesk](https://TheBridalDesk.etsy.com).

## What's Included

- **`WeddingPlannerPro_WebApp.html`** — The full interactive planner (18 tabs, works offline)
- **`HOW_TO_USE.html`** — Quick start guide with unlock code and tips

## Features

18 planning tabs including Budget Dashboard, Guest List, RSVP Tracker, Seating Chart, Vendor Tracker, Day-Of Timeline, Photography Shot List, Music & DJ, and more.

- Saves automatically in your browser (localStorage)
- Export your full planner as a PDF via the built-in Export button
- 8 color themes — Dusty Blue, Sage Green, Blush Pink, Lavender, and more
- Works on desktop, tablet, and mobile

## How to Use

1. Download `WeddingPlannerPro_WebApp.html`
2. Open it in Chrome, Safari, Firefox, or Edge
3. Enter your unlock code and start planning
